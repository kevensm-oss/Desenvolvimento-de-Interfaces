# Atividade: Primeira Página HTML5 💻

Crie uma página HTML simples sobre um tema de sua escolha.

---

## ✅ Requisitos da página

A página deve conter, no mínimo:

- [ ] Um **título** para a página (`<title>`)
- [ ] Um **título principal** utilizando uma tag de cabeçalho (`<h1>`)
- [ ] Pelo menos **dois parágrafos** de texto (`<p>`)
- [ ] Uma **lista** ordenada ou não ordenada (`<ol>` ou `<ul>`)
- [ ] Um **link** para outro site (`<a href="...">`)
- [ ] Uma **imagem** (`<img src="..." alt="...">`)
- [ ] Uso de **atributos** nas tags, como `href`, `src` e `alt`
- [ ] **Estrutura básica** de documento HTML: `html`, `head`, `title` e `body`

---

## 💡 Exemplos de tema

Você pode criar uma página sobre:

- Hobby
- Profissão
- Cidade
- Filme
- Esporte
- Tecnologia
- Música
- Qualquer outro assunto de seu interesse

---

## 📦 Entrega

Envie o arquivo `.html` criado na atividade na pasta `projetos-web`.

Dentro de `projetos-web`, crie uma pasta específica para esta prática. A estrutura inicial no repositório do GitHub deverá ficar assim:

```
projetos-web/
└── primeira-pagina-html5/
```

---

## 🔍 Antes de enviar

Abra o arquivo em um navegador e verifique se todos os elementos estão sendo apresentados corretamente.

---
