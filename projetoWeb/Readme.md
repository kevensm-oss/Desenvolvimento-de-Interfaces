# Criar uma página HTML simples

Crie uma página HTML simples sobre um tema de sua escolha. A página deverá conter, no mínimo:

1. Um título para a página.
2. Um título principal utilizando uma tag de cabeçalho.
3. Pelo menos dois parágrafos de texto.
4. Uma lista ordenada ou não ordenada.
5. Um link para outro site.
6. Uma imagem.
7. Utilização de atributos nas tags, como href, src e alt.
8. Uma estrutura básica de documento HTML, incluindo html, head, title e body.

## Exemplo de tema

Você pode criar uma página sobre um hobby, profissão, cidade, filme, esporte, tecnologia, música ou qualquer outro assunto de seu interesse.

## Entrega

1. Envie o arquivo .html criado na atividade na pasta projetos-web.
2. Dentro de projetos-web, crie uma pasta específica para esta prática.
3. A estrutura inicial no Repositório do GitHub deverá ficar assim:

   ```
   projetos-web/
   └── primeira-pagina-html5/
   ```

4. Antes de enviar, abra o arquivo em um navegador e verifique se todos os elementos estão sendo apresentados corretamente.

## Desafio extra ⭐

Para quem quiser praticar um pouco mais, acrescente outros elementos HTML estudados no módulo, como diferentes níveis de títulos, imagens adicionais, links ou outras listas.
